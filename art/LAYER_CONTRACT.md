# 主角分层与换装素材契约

> 已废止：本文件记录被否定的旧拆件/程序关节方案，仅供追溯。不得继续用作生产或换装模板。当前完整帧与未来逐帧模块规范以根目录 `CHARACTER_MODULAR_RULES.md` 为准。

本轮交付一套服装、四方向待机/行走，不包含换装玩法或 UI。

## 坐标与时间

- 原点为人物脚下世界坐标；每帧画布 128×128，原点像素 (64,112)。
- 角色可见高度约 88 px，所有动作和部件共用画布与原点，禁止按每帧边界重缩放。
- 图集 12 列、8 行：正面待机、正面行走、背面待机、背面行走、右侧待机、右侧行走、左侧待机、左侧行走。
- 待机 6 帧、6 FPS；行走 12 帧、每周期 40 世界像素。当前移动速度 80 px/s，即持续直行时每周期 0.5 秒。
- 同一角色所有层由一个权威帧索引驱动；行走进度使用实际移动距离，撞墙停步不继续原地滑走。
- 左侧由右侧镜像得到。轮廓完全一致，但当前左右光照也会镜像，这是 V0.1 限制。

## 换装层组

| 组 | 图集槽位 |
| --- | --- |
| 基础身体 | far_leg、far_arm、torso、near_leg、head、near_arm |
| 头发 | hair |
| 上衣 | far_sleeve、jacket、near_sleeve |
| 裤装 | far_pants、near_pants |
| 鞋子 | far_shoe、near_shoe |

底层身体采用贴身内衬与完整四肢，不依赖外套、裤子和靴子才能成立。基础皮肤和服装图片分离，所有部件原始透明裁片保存在 `art/parts/`。

槽位由远到近的绘制顺序见 `assets/hero/actor.json` 的 `slots`。远侧手脚在身体后，近侧手脚在前；上衣躯干盖住上臂接缝，独立袖子跟随同一手臂骨骼。帽子、背饰尚未制作；将来新增需先定义方向遮挡顺序，不能插入独立计时器。

后续替换一件衣物，只替换该组图集；必须保留画布、原点、动作行、帧数和动作时间。可以新增配套源部件后重新烘焙，不应重画已接受的人物身份或修改碰撞体。

## 动作来源与质量边界

静态身份、自然环境和独立部件使用 `generate2dsprite` 指定的 host image 路由生成。当前 `route_media resolve --kind video` 返回 no-route：没有图生视频 API 配置，也没有 Grok CLI。

因此动作使用同一套生成裁片的程序骨骼/投影关节变换，双腿有真实前后交替、抬脚、手臂反向摆动；不是整张静态人物平移。行走支撑期按每周期 40 px 设计，运行时按实际位移推进帧。帧离散化、近似投影和裁片结构仍可能有轻微剪纸感，不等同逐帧手绘。

`tools/prepare_art.py` 可从保留的生成源图重建部件、14 个同步图集、动作预览与接触轨迹。该脚本处理和变换生成像素，不是另行绘制角色。当前资源应认定为 **V0.1 可运行的分层动作初版，尚非最终发行美术质量**。
