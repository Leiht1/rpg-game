## 诊断
- 正式角色与view_v01树石沿用3.1近正交斜俯视。岩石有明显顶面及较短前侧体块，缺少认定为纯俯视、需要重绘的依据。
- 原矩形下边为原点Y+8，画稿实际底缘约Y+6。正式candidate_mode=1的影以(4,4)为中心、树固定宽26、石宽为显示宽*.43，透明度.23的单层多边形边缘明显，没有按根/石底形状贴合。
- 正式影在PNG前，没有独立树冠影，也没有PNG后局部底缘覆盖。candidate_mode=0的旧土床和草叶不是当前正式运行路径，不能当作当前原因。
- 物件清晰外轮廓不需要模糊；连续底缘加通用硬影导致分离。地面已有较丰富高对比小形状，抢夺小物件注意力。两树两石轮廓复用仍可读，原生成已有尺度变化；本轮不改分布，不能声称解决全世界重复度。
