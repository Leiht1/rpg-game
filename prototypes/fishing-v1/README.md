# 钓鱼 V1 · 独立候选预览

状态：pending_user，等待本批试玩与审美确认。没有正式接入。

双击项目根目录 `Start-Fishing-Preview.cmd`。Godot 4.7.2 编辑器可打开 `scenes/fishing_preview.tscn` 按 F6；不要修改项目主场景。预览使用隔离测试世界，启动即站在湖岸并装备现有可制作鱼竿，附近有三个鱼群点。首次加载需等待地图就绪。

WASD 沿岸移动，持竿靠近鱼群按 E，角色只会朝左/右侧视抛竿。浮漂消失并出现感叹号后，小游戏自动打开；圆点进入绿色安全区时按 Space。安全区宽度 21%，每轮随机换位置。命中两次成功，失误或超时累计三次失败。Esc 取消本次钓鱼，窗口失焦也取消；空闲时 R 回到首个鱼群岸边。滚轮沿用原相机缩放。

成功后侧视提竿、钓获出水和水花，再通过现有库存/获得提示得到一件收获：通常为“湖鱼（候选）”，低概率为金币或密码锁宝箱。两种彩蛋没有使用功能；金币描述为“闪闪发光，看起来很值钱。”。满包则放回，不产生虚假获得提示。鱼和物品只留在本次临时世界，退出丢弃。原本就可制作的鱼竿配方、耐久、正式造型与配置不变；本预览仅使用去掉画死鱼线的候选图，持握缩放恢复原配置 0.24（256×256 画布），不再使用早期 0.48 放大版。

鱼群位置按整片波纹与水花占用检测水面，并在波纹绘制时逐段过滤岸上区域；加深后的模糊鱼影保持少量慢动。候选素材在 `art/` 子目录，侧视动作关键姿态在 `side_poses.json`；来源、原图、提示词、处理记录与 SHA256 位于项目根目录 `art/fishing-v1/` 和彩蛋增补 `art/fishing-v2/`。由于 prototypes 全局被导入器忽略，运行使用同目录的原生压缩 ImageTexture `.res`，不解除旧原型导入隔离。

优先审核：原尺寸弯木竿与双手连接、左右侧视抛/提竿姿态、局部鱼群与浮漂可读性、小游戏节奏及成功那一下的反馈。当前复用原角色部件，没有新增角色 PNG、正/背/斜视动作，也没有鱼线物理或真实鱼 AI。

具体文件、测试证据及边界见 `reports/fishing-v1/REPORT.md`。普通 Start-Playtest、正式 assets/data、玩家存档均不由本候选修改；未批准正式使用。
