# 五区样例地图 V0.1

入口：根目录 Start-Biome-Preview.cmd。0 总览；1–5 分区近景；L 隐藏/显示区域名称。静态2400×1320样例，无角色、踏草或交互。场景为 prototypes/biome-v01/preview.tscn，独立于正式游戏。

## 区域骨架

| 区域 | 位置/环境逻辑 | 景物与留白 |
|---|---|---|
| 出生草地 | 中央连接五区 | 中央半径230净空，外围少树少石 |
| 森林 | 西北成片林地 | 高密树群围合145半径林间空地，少量落叶 |
| 山地 | 东北岩脊 | 正弦岩脊带集中石群，外围碎散，少树 |
| 水岸 | 东南湖岸 | 距离场决定干湿边和水面，沿岸石带，水内不放物件 |
| 稀疏原野 | 西南开阔地 | 极少树石，大面积地表留白，点状花叶 |

## 生成顺序与复用边界

1. 固定区域中心与椭圆影响半径，连续权重给出区域归属和边缘混合；位置按比例可移植到后续布局数据。
2. 区域规则决定树/石/装饰候选，森林空地、出生留白、岩脊带与岸线距离优先于随机概率。
3. 软混合地面色调，森林边缘降低树密度由区域归属形成，山地岩脊向外围散开，水岸使用窄过渡带。尚无专用过渡PNG。
4. Seed只改变受规则约束的候选位置、轮廓与低密度点缀；不会随机挪动五区骨架。

layout.gd提供weights / biome / lake / objects接口，输出可复用物件记录（位置、区域、类别、轮廓编号）。版本biome-layout-0.1.0；修改布局/摆放规则须升级此版本。正式world_generator仍为windrest-0.3.0-cartoon；没有接入超大地图、流式区块、碰撞或采集逻辑。

当前地表复用已确认A方向自然绿版本，镜像采样；区域着色是展示规则，不是新地表画稿。水体仅色面示意；山地区暂无真实高差。地面镜像重复、两种树石轮廓重复、部分网格节奏仍可辨；后续新增素材必须按ART_STYLE与受控流程先出候选。本轮样例pending_user，不能当成完整素材库或已验收正式地图。
