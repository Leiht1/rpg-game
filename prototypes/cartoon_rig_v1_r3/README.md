# 极简卡通造型 V3 独立预览

运行 RunPreview.bat；编辑 OpenEditor.bat。独立 project.godot，正式游戏不加载本目录。

根据本轮用户参考重新制作大色块头发、点状眼睛、小白T恤、青色短裤、细杆四肢和圆末端。没有复用v11或精细版身体素材。头部遮颈，袖子与手臂、裤管与腿分别画成连续部件。素材来源为内置image_gen，经generate2dsprite受控流程登记；源图、提示词与回执见 ../../art/cartoon_rig_simple_v3/。原始来源费用和精确模型版本未知，参考图仅用于结构和简化程度，不直接使用其中资源。

头部56×45，衣身正面24×24/侧面20×24，手臂8×25，腿9×27，以上为128×128坐标中的逻辑尺寸；实际纹理4倍。脚底参考(64,112)。正面肩根在衣身两侧；侧面远臂在衣身和双腿后，头部后移2px。中央衣身仅带腰部连接带，裤管分别跟随腿。

六个Node2D主支点、六个Sprite2D；八条可编辑原生AnimationPlayer动画，支持正面/右侧/镜像左侧、呼吸/行走/奔跑/挥手、正常/半速/暂停、关节显示和1倍/4倍预览。build_rig.gd离线重建character.tscn；运行时不播放整身帧图，也不依赖Python。

本轮重画造型与部件，沿用并重新适配原有动画曲线；新增动作仍可通过关键帧复用。循环时长为呼吸1.8秒、行走.64秒、奔跑.44秒、挥手1.6秒。evidence/是Godot实际渲染的检查帧和GIF，不用于运行时。

边界：仍是刚性单段四肢，袖口不能柔性变形；奔跑没有独立腾空段；原地预览没有验证世界移动中的滑步。本轮重点是用户要求的造型简化，最终审美与自然度等待用户验收。没有全量回归、NPC批量或性能压力测试，不提供新的性能承诺。未接入正式游戏。
