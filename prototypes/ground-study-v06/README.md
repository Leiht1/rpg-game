# 风栖原野 · 三个独立地面美术样板

直接打开 A.html / B.html / C.html，或 index.html；无需安装或启动服务器。comparison.html按同视角显示三张完整截图。页面支持隐藏参照物、1:1像素显示、保存同视角PNG。

A 柔和手绘：疏短圆笔草痕、轻柔近色笔触，留白最多。
B 精致卡通：明暗短草笔触组合、小范围亮色细节，更精致丰富。
C 自然原野：细长有方向的草痕，疏密成片，原野肌理。

全部使用同一张实际游戏导出的1280×720透明参照层，原有树石、人物、接触阴影和布局不变。无独立新增草簇贴图，不使用前轮shader色块方案。

地表原图通过generate2dsprite的route_media.py受控生成，实际附上正式tree_0.png、rock_0.png及角色同屏参照；三次local:codex-cli / codex-image_gen调用，art_source=host_image，模型底层名称与实际费用未知，回执estimateUsd=0代表订阅调用估计。原图、提示词、参考哈希及job回执均保留。原图按整幅地表在Godot中缩放渲染，不平铺、不裁片；scene-overlay保持1280×720不缩放。源图和预览参数见processing.json。

已实际检查三张完整场景渲染、纯地表与浏览器页面；未见明显几何拼接、迷彩色带或规则平铺接缝。仍是待用户选择的样板，不能据此宣称已通过用户验收。每个方案只是一屏地表画稿，未制作无缝世界纹理；本轮不做集成或任何玩法测试。

review.json保存正式相关文件修改前后哈希对照，全部一致。没有修改正式游戏脚本、素材、场景、启动入口。
