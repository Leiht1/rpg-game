## 本轮结构修正

- **头部**：重新绘制为没有颈部的完整头部，头部下沿覆盖中央衣身顶端。不是拿旧脖子平移遮掩。
- **手臂**：袖子、短手臂、圆手为同一张连续部件。袖口与手臂使用相同旋转、位移；没有躯干上的固定袖口覆盖层。
- **腿部**：每侧短裤裤管、短腿、脚为同一张连续部件，左右独立。中央衣身只含一小段腰臀连接带，不再含整条短裤。
- **中央衣身**：白色衣身与短腰带，重画去除多余肩部凸起，避免出现一个不动的假袖子。上部与袖根重叠，下部与裤管根重叠。
- **遮挡**：正面双臂对称排列；侧面区分远近臂。挥手时近臂置于头部前方并调整角度，避免大头把手完全遮掉。

依旧只有六个主支点和六个 Sprite2D，原生 AnimationPlayer 内嵌八条可编辑动画，未使用整身序列帧播放。character.tscn 可直接在 Godot 动画面板调整；build_rig.gd 是离线构建器，重新运行会覆盖本实验保存的动画。周期沿用呼吸1.8s、行走.64s、奔跑.44s、挥手1.6s。
