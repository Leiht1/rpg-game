# 景物独立样板 · 待用户确认

本轮最终范围：树根与地表衔接、树受击渐进变形/回弹、砍完原地0.3秒渐隐。无倒树、无树桩、无新采集玩法。草地/林下/裸土三组树石新画稿供同屏对照，石头仅作静态接地参照。

运行 Start-Preview.cmd。1/2/3切地表，Tab切旧画稿/新候选，H受击，F模拟砍完渐隐，空格重置。固定布置的真实Godot场景、原角色资源、原terrain Shader和原逻辑画布、1280×720 Camera2D 1×。不读写正式世界身份，不更改正式生成器/分块/角色/E键/收益。

地面顺序为地表→独立柔冠影→按脚底Y排序的景物和角色。树为225顶点384三角形主体网格，底部24单位固定切片，接缝重叠1单位，Shader在根部位移/斜率为0。石底固定12单位。接触草叶是真实生成画稿的一部分。根部、覆盖与主体原地一起渐隐，冠影随透明度消失。没有每树持续_process。

旧图对照只对比view_v01画稿，未重现正式第二版屏幕取色融合；不是正式整场景before截图。裸土地复用shore画稿，只用于接触技术样板，尚无正式泥地分类。新石画稿较扁，三地表的根/草颜色及切片衔接仍待视觉确认。没有新音效或粒子。

surface_policy.gd是最初完整需求中的独立适生策略草案，未接入正式生成器；候选版本environment-policy-0.1.0。正式windrest-continent-0.6.0不变。它解析Shader混合权重并拒绝裸岩阔叶树/水域，不含正式跨块间距裁决与通行验证；本轮收缩后不继续扩展。
