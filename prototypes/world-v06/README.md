## 独立生成设计

1. 先完整生成12–18区域的抽象连接树，限制主树度数，混合延续和分支。与出生点、世界中心角度无关。
2. 再布局固定树：子区域围绕其父区域尝试有间距的空间位置，允许非相邻区域宽幅接触。短距离非交叉附加边带来少量环路。坐标只在最后整体平移、等比适配并施加Seed长宽变化。
3. 区域有不同半径、长宽、朝向和不对称多尺度轮廓。区域体与可变宽连接体的并集构成陆地距离场，再加低频域形变、小尺度岸线变化。不是旧分区外加海洋遮罩；原最近节点生态算法被替换。海洋来自陆地场之外，湖河来自独立内陆计划。
4. 陆地结构确定后给区域分配森林/山地/草原，分支较多的连接区域提高草原概率。生态用不规则区域体的有符号距离融合，不要求均分、不禁止同类相邻，边界宽度受湿润场变化。保留密林/疏林/空地/石群子环境。
5. 将静态陆地场和生态权重缓存为385² RGBA浮点图，世界坐标双线性采样；陆地构建约数秒发生于计划阶段。后台工作器共享只读缓存，独立噪声。湖泊完整包络必须在内部且避让连接骨架、出生；连续弯曲河段同样检查，不随机洒蓝点。
6. 出生从自然草原内部选取，要求海岸净距；Seed随机评分，不偏向几何中心、不改变生态。原110–180单位必要树石净空保持。检查2000单位内真实树和石数量。

## 验收入口与限制

`tests/test_world_v06.gd`：PRNG固定2026101606连续抽10个Seed、不筛掉失败；384²洪泛带25单位净空、重复/工作器采样、图连接逐48单位检查、出生/资源、块边框、较小尺寸。`tests/capture_world_v06.gd`：前5个Seed实际正常物理移动跨块、真实M按键及全图截图、缓存一致、缩放夹紧、加载缺口。`tools/report_world_v06.py`：数据地图、调试叠加和同尺度比较页，不产生游戏美术。

`initial-diagnostic/`保存早期水系全部被旧尺寸规则筛掉的10 Seed；`embedded-growth-diagnostic/`保存调整水系后、收紧“完整抽象树先行”之前的10 Seed结果。最终记录位于reports/world-v06根目录。所有图环数都是E−V+1，不等同于可见内海数，也不保证所有分支上都有另一条路线；区域体重叠会额外拓宽地面连接。

保留质量判断：宽幅圆润区域体仍可辨识，个别Seed可能偏枝状或陆地覆盖偏小，生态边界仍是连续融合。它是待用户看全图选择的候选，不因数值检查通过就视为自然程度已批准。没有新增素材，海洋复用湖水表现，尚无专用深海层次。启动计划缓存有约秒级等待，不把它当成实时帧耗时。只完成本候选，等待全图确认再考虑正式接入。
