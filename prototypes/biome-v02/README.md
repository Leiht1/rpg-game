# 随机世界与多生态地表 V0.2（独立候选原型）

打开 `preview.tscn` 运行，或运行本目录 `启动预览.ps1`。正式入口和 V0.1 均未替换。

- 输入整数 Seed 后回车或“应用 Seed”；“新世界”创建时间 Seed 并保存；“读取世界”沿用保存的 Seed 和生成器版本。原型专用 user://biome-v02-world.json，不读取或写入正式存档。
- 0 全图；1 森林；2 山地；3 原野；4 水岸；5 林缘；6 山麓；7 林山交界；8 出生点。WASD/方向键、Shift、滚轮沿用现有操作。近景可实际行走；树石有脚底碰撞，深水不可走。
- 已确认角色场景、动画、速度及树石原画保持；独立适配脚本关闭采集。没有踏草或新玩法。

生成器 biome-world-0.2.0，6144×4096 世界单位。湿度与山地连续多层噪声、域扭曲、Seed 随机数量/位置/长宽湖泊，出生空地仅作为局部约束。不是固定区域中心换位。世界坐标权重场每16单位采样，由同一张全域场连续插值，没有区块局部UV或局部随机状态。地表、物件、岸线、可行走区域共享权重。

四种独立模型生成纹理以连续权重混合；森林腐殖土苔藓、山地裸岩碎石、草地和岸边泥沙来自不同裁片，不是草图上叠透明色。纹理采用四邻域随机偏移采样平滑混合，减少直接平铺/镜像。浅水深水由岸线深度场混合，水面是原型程序材质，不是新水体原画。过渡的地面细节来自材质本身；树石、花叶密度随权重与局部聚集场变化。
