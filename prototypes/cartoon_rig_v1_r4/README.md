新增动作：
- 持斧砍树：1.65秒循环，举斧蓄力、下挥、命中停顿、收回。斧头绑定同一手部支点，工具角度独立关键帧控制；树仅轻微受击摆动。
- 弯腰拾取：2.2秒循环，俯身伸手、抓取短停、起身把物品带回。末尾物品淡出并回到地上，以便重复观察。

正面和侧面各新增两条AnimationPlayer动画，总计18条；左右共享。角色沿用用户确认的V3八个方向部件，没有生成完整人物序列帧。单段手脚与衣物一起运动，头身和肩髋保持共同连接点。斧、树、果实只是独立预览的参照，不包含实际工具、采集、背包、树木受损或碰撞系统。

资源：character.tscn保存原生动画；build_rig.gd与action_clips.gd为离线构建器，重建会覆盖此实验动画；运行时不依赖Python。art/保留角色、三件道具、原图和整理记录，art/provenance保存生成提示词与回执；完整道具来源位于../../art/cartoon_rig_actions_v4/props。内置image_gen生成1张道具图，无外部下载；精确模型及费用未知。

evidence/包含四个新动作GIF、192张引擎检查帧、相位图、检查报告。采样帧仅供检查，不参与运行时动画。Godot4.7.2实际渲染，24项相关检查通过；检查范围是新动作参考点、持物、目标接触、脚底与切换后道具清理，不是全量回归或视觉通过证明。
