# 简化卡通角色动画实验 V1

2026-10-16，独立 Godot 4.7.2 Stable 工程，候选待用户验收。未接入正式游戏。

双击 `RunPreview.bat` 运行；`OpenEditor.bat` 打开独立编辑器。启动器默认使用本机 D 盘 Godot，也支持 GODOT_BIN。换电脑时可直接用 Godot 4.7.2 导入这里的 project.godot。

- 切换正面 / 右侧 / 左侧，呼吸 / 行走 / 奔跑 / 挥手。
- 正常速度 / 半速 / 暂停继续；显示隐藏关节支点。
- 同屏 128×128 原尺寸与 4 倍预览；角色共用脚底参考 (64,112)。
- 方向切换保留动作相位，左侧整体镜像右侧；动作切换混合 0.14 秒。

## 可编辑资源

`character.tscn` 是已保存的 Node2D + Sprite2D + AnimationPlayer 场景，八个动画在 AnimationLibrary 内，可直接在 Godot 动画面板改关键帧。运行时不重新求姿势、不烘焙完整人物帧。`build_rig.gd` 是一次性资源构建器，重新执行会覆盖本实验 character.tscn；手动修改动画后不要随意重建。

六个主支点：躯干骨盆、头、左右臂、左右腿。七个 Sprite2D：六个身体部件加一层随躯干运动的袖口遮挡。躯干白 T 恤和短裤为一张连续部件，避免服装悬空。没有肘膝、网格蒙皮、表情或换装系统。

`art/` 包含全新生成的专用部件原图、正侧面高清透明 PNG、袖口遮挡、整理坐标和来源回执。部件以 4 倍密度保存、Sprite 缩放 0.25；角色逻辑画布仍是 128×128。头含脖子高 53 逻辑像素，头颅约 48 像素，中性全身约 97 像素，头颅约占 49%。两方向的轮廓宽度略有差别，按同一逻辑高度和脚底坐标登记。

周期：呼吸 1.8 秒、行走 0.64 秒、奔跑 0.44 秒、挥手 1.6 秒循环。行走使用约 60% 支撑段的匀速后移、40% 低弧回摆，左右错半周期；腿根位移补偿上身起伏，手臂反向摆动。奔跑提高摆幅、步频、重心起伏和侧面前倾。双脚待机固定。

## 复核材料

- evidence/preview.png：实际引擎原尺寸/放大同屏。
- evidence/front_*.gif、side_*.gif：引擎逐次采样导出的循环动图，仅供检查，不是运行时素材。
- evidence/gait_phases.png：侧面行走/奔跑相位。
- evidence/left_wave_pivots.png：镜像方向、挥手与支点。
- evidence/verification.json：163 项资源、首尾、脚底参考、方向/动作按钮及速度检查，无失败。
- REPORT.md：实际工作量、质量边界与复用结论。

源代码复核入口：prepare_parts.py、build_rig.gd、verify.gd、capture.gd、make_review.py。运行 PNG 整理/复核动图需本机已有 Pillow，播放预览只需要 Godot；没有新增依赖。
