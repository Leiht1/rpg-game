# 两台电脑独立测试

两台电脑各有独立账号、激活凭证、证书、世界及登录记忆。它们不互相同步，不覆盖原 `dist/network-v0.1.0` 部署、`server-data` 或源码 `config`。服务只监听本机 `127.0.0.1:24871`，无需添加防火墙规则；自动双客户端补测另用24872等隔离端口。

在每台电脑的项目目录分别执行一次（Godot路径按实际安装位置调整）：

```powershell
./tools/Independent-Test.ps1 -Action setup -GodotPath 'D:\Godot\Godot_v4.7.2-stable_win64_console.exe'
```

默认使用Codex内置Python，需有cryptography和Pillow；其他环境可传 `-PythonPath`。必须是Godot4.7.2。每台电脑都需要本地源码和正常的Godot导入缓存。

配置存于 `%LOCALAPPDATA%\Windrest\IndependentTest-v1`：`server.json`、`client.json`、`machine.json`、`Data`、`Runtime` 和独立登录记忆。不要删除整个目录或用另一台的目录覆盖它。重复setup只保留现有配置；发现不完整目录会拒绝覆盖，应先另名保留并检查。运行路径/设备不匹配也拒绝直接使用。Windows封装环境可能将LocalAppData解析到应用LocalCache，以server.json中的data_dir为实际数据位置。

启动服务器（保持窗口开启，Ctrl+C正常关闭）：

```powershell
./tools/Independent-Test.ps1 -Action server
```

另开窗口检查及启动客户端，可执行两次client启动两个客户端：

```powershell
./tools/Independent-Test.ps1 -Action check
./tools/Independent-Test.ps1 -Action client
```

首次账号使用本机 `Data/Accounts/FIRST-ACTIVATION.private.json` 中的测试凭证；双客户端分别使用两个不同账号。同账号重复登录会撤销旧会话。凭证不要提交仓库或公开分发。客户端保留原单机入口；需要联机时选择联机模式，单机仍使用原单机存档。

每次服务启动自动新增完整数据备份。停服后可执行 `-Action backup` 再生成一份备份；不自动清理历史备份。Git只同步代码、说明与测试结论，不同步上述账号、私钥和世界。更新代码前先停服和备份，再更新，再启动；不重新初始化。两台电脑的旧数据都留在各自设备，另一台的现有内网服务器保持原样。

当前设备另有本地 `Start-Independent-Test-Server.cmd` 和 `Start-Independent-Test-Client.cmd` 便捷入口；CMD依项目规则不提交，换设备用上述PowerShell入口。
