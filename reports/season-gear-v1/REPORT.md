# 四季衣物与轻量暑热 V1 · 本地完成

日期：2026-10-24。Godot 4.7.2 stable / Compatibility / RTX 5060，项目默认窗口1280×720。本轮新增仅四件衣物与用户追加的轻量暑热；没有联机测试、部署、发布、提交、推送或正式玩家档投放测试物品。

## 正式接入

四个独立装备实例：羊毛衫、羊毛帽、草帽、蓑衣。outfit/head 原槽、配料/库存/快捷栏引用/原子提交路径保持，普通 C 制作的现有“野外用品”分类默认开放。材料与效果唯一参数来源为 data/recipes.json、data/items.json；环境/暑热唯一公式参数来源为 data/weather_body_rules.json。

雨具按剩余淋雨比例相乘，组合仍弱于原雨伞；工具手不受衣物影响。羊毛衫仅上身/双臂、蓑衣仅原躯干层，腿与手的原素材保持。新绘制素材在 assets/season_gear/v1，37个PNG包含6个逐列轮廓数据图，不把这些遮罩当新美术。

## 轻量暑热

真实环境温度与晴天日照、实际步行/奔跑/原有耗精力劳动进入平滑热负荷。正常夏季恒定最热温度+草帽连续普通步行全天不炎热；不戴帽长时间暴露才逐渐炎热；戴帽极长连续高强度活动仍可积累。原寒冷体感链不改，保暖衣物不额外加夏季负荷。炎热唯一惩罚为精力恢复速度降低15%，实际接原睡眠恢复；无生命、疾病、新消耗或体力恢复惩罚。原身体文字UI显示，无新条。

热状态作为 body.summer_heat 可选 version1 写原原子快照，旧档安全默认，非法值先整体拒绝，无新存档路径。睡眠受热时原渐进恢复倍率生效，原时长和退出机制保持。

## 尺寸、位置、图层及衔接

按用户纠正撤掉了“按发型外框缩放帽子”，也不拿帽子非等比挤压去遮住大丸子。最终帽型每视角固定锚点、固定显示宽度、等比绘制，男女及所有发型相同。原头发PNG/节点尺寸/位置不改；只在戴帽时通过 Shader 按帽型及逐列下缘遮去上方穿出部分，卸帽完整恢复。低马尾、长发、双马尾下方结构保留。帽子原图经真实重绘，草帽改薄近沿及独立远帽沿，远沿在头部后，去掉原正视大面积暗色帽底盖头问题。

衣物正面双手在衣身前：右侧仍是原手臂，左侧原图单一前景显示，原后层隐藏，遇原工具的空闲臂前景副本不重复显示；侧背恢复原规则。羊毛衫衣身与袖子面料保持奶白色，仅露出的手部参与原肤色着色，解决误染色差。背包预览与睡眠侧头同步入口，原闭眼保留。

逐个查看了十发型×男女×两套搭配×正背左右四向，每格同屏正常尺寸和放大两倍，共320个真实角色渲染。核对帽体、刘海/额头、耳侧、后脑及衣物/手的位置和遮挡。额角衔接发现约2源像素的边缘空隙后，草帽固定前视锚点下移3源单位，并将水平裁切改逐列下缘遮罩，未改变帽子尺寸。

## 失败与修订边界

早期686项主要覆盖结构与数值，未覆盖真实视觉，不能作为当时美术合格证据。用户指出的蓑衣挡手、动态缩放/侧帽错位、袖子误染、正面帽底遮头均已按新要求修订。随后补充实际GPU裁切与接缝探针；早期探针把无穿出的莫西干视角、鼻前自然帽沿悬出误判，已针对真实应裁像素及头皮界面纠正；不以这些探针替代上述逐视角视觉检查。
