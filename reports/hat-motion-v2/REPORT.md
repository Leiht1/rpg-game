# 帽子转向/动作闪大、接缝与草帽残发修复 V2

2026-10-24 / Godot4.7.2 stable / Compatibility / RTX5060 / 项目默认1280×720。本轮只改现有衣帽显示与对应验证，不新增/重画美术，不改配方、数值、身体或雨伞系统；不联机、发布、部署、提交或推送。

## 已复现的问题与修复

1. 原 attachment 节点先用单位缩放加入开启物理插值的角色，再改成真实帽子缩放。转向重建节点时可能把单位缩放插入一帧；原 signature 又包括完整主手装备状态，工具耐久变化也会无谓重建帽子。现在先设好最终比例/位置再入树，并重置新节点插值历史；显示签名只看头饰/衣服物品ID及视角，主手切换/耐久不重建衣帽。
2. 原裁发逻辑把整帽 alpha 内的上部头发保留。草帽整帽轮廓包含远帽沿，而远沿在头后，导致这些保留发像素可能露在前景帽体未覆盖的区域。现在上部头发完整藏入帽体，按逐列下缘恢复下面的刘海、耳侧、长发及马尾；帽子每视角尺寸与锚点仍固定且等比，不按发型变形。
3. 下缘留3个头部源单位的遮挡重叠（正常角色约0.75像素），让头发进入近帽沿下面，消除滤波/轮廓量化可能留下的微缝。卸帽仍恢复原材质和完整发型，原头部/发型PNG不变。

运行改动仅 scripts/equipment_appearance.gd 与 scripts/hat_hair_clip.gdshader；37张正式PNG和对应来源哈希保持一致：True。

## 验证

- tests/hat_motion_v2.gd：**2176项0失败**。转向配合呼吸、走、跑、拾取、砍树、采矿、挖掘，2种帽子各168个渲染帧样本，共336个切换帧。以真实GPU绘制边界识别帽子，旧代码最大达到目标全画布边界的2.693倍；修正后最大0.981倍，未越过目标边界。这里比值是可见像素包围盒/当前目标画布包围盒，不是声称不同视图纹理的透明边距完全相同。
- 十发型×男女×四向×正常尺寸/放大显示320个角色。上部头发GPU探针80组，111671个应隐藏源像素无残留，包括整帽 alpha 内但前景帽片未覆盖的区域；80组头皮接缝探针均通过，最大1源像素抗锯齿边界，无连续≥2源像素透明缝。
- tests/hat_legacy_v2.gd：**32项0失败**，另外核对旧版原头贴图（头发与脸同图）的四向、上部裁发、接缝和卸帽恢复，不只测创建角色。
- tests/hat_refresh_v2.gd：**32项0失败**，两种帽子四向换主手/连续3次工具耐久变化，实际帽子节点身份保持，避免劳动中的无谓重建。
- tests/hat_static_v2.gd：测试拼图每格独立裁剪后追加**1840项0失败**，保证前一行人物的脚不会串入下一行帽顶，避免把测试排版中的异物误读为残发。该次是显示夹具修订后的复核，不与前面重复项相加当成功能覆盖数。

实际查看全部十种发型的原色四向接触图、旧版头图及连续帧几何对照，核对帽型固定、额头/耳侧/后脑连接、草帽顶部干净、原双手与服装关系。head-contact.png、legacy-heads.png 和 motion-* 为本批待确认临时媒体，不作为新的正式美术批准。
