# 联机延迟移动与登录记忆 V4

2026-10-21，Godot 4.7.2，默认1280×720。仅修改联机移动和登录记忆及其必要打包组件。

## 修复

旧服务每次最多结算0.2秒，客户端却持续前移，再按固定半程延迟估算校正；延迟增加时在空地也会拉回。现客户端发送逐帧输入序号/时长，服务按真实时间额度结算，回复确认序号；客户端去掉已确认部分并重放未确认部分，保留地形与速度校验。重发已确认输入不会重复位移；服务保存失败会回滚状态和输入确认。地形掩码解码结果按世界缓存，避免每次移动重复解码整张地图。

「记住密码」默认不勾选；成功登录始终保存用户名，勾选后用Windows DPAPI CurrentUser保存加密密码，取消即移除密码。跨服务器地址不预填；不自动登录、不缓存会话/激活凭证，改密成功更新已记住密码。新增LoginVault.exe需和客户端一起保留，源码Godot测试也复用本机分发目录中的该组件。

## 实际验证

- 14个隔离服务用例通过。新增延迟批次精确位移/确认、重复请求不重复移动、时间额度拒绝、保存失败回滚、不可通行格分段防穿越、NaN/Inf/非法时长拒绝。
- 打包客户端真实HTTPS、默认窗口，服务每次移动额外等待220ms和550ms，各18项通过；连续移动向后帧均0。包含本地立即响应、旧轮询保护、断连预测上限、恢复连接、停步不回拉、奔跑、立即反向、鼠标与数字快捷栏、图标及物品操作菜单。
- 550ms最终连续行走：73帧样本，向后0帧，前进186.68单位（该段包含先前主动暂停请求后的恢复）。这不是网络吞吐或长期速度基准。
- 加密往返、缓存不含明文密码、服务器地址隔离、取消保存通过。源码及打包客户端分别以三个独立进程验证保存→重开预填→取消勾选→重开仅用户名；原生窗口核对密码圆点与勾选布局。
- 本机服务器更新前已停服备份，更新后TLS24870恢复；重启前后数据库持久化状态完整相同。未重新初始化Data，未改真实账号或世界。
- 客户端及独立服务器ZIP同步更新；独立服务器包不含Data、私钥、账号凭证。客户端包不含测试凭证或记忆缓存。

## 使用与边界

所有玩家重新解压最新客户端；服务器也必须更新本批，保留原Data与Config。本机服务器已更新。同事若另起独立服务器，也要停服备份后替换Server程序。账号、世界存档无需重建。

尚未在同事电脑的实际局域网复测；高丢包/长时间断线、16人并发及长期性能未测。原48单位保守地形掩码与其他尚未多人化玩法保持原边界。没有新增自动更新或自动登录。
