# 交互与野猪动作 V3

2026-10-23；Godot 4.7.2，项目默认1280×720，仅本地源码。

## 结果

- 背包和地图按钮取消悬停提示；右键选物品时空闲持握不再释放，劳动取消后同帧刷新。
- 快捷栏再次使用已装备实例调用原卸装事务，回原快捷格，保留联机路由及唯一实例。
- 徒手单手由上往下击打，上身前倾，另一手不挥动；背面抬手向身体外侧保持可见。
- 正视棍棒改双手沿同一棍柄握持，向前下方挥击并缩短透视；侧背仍用采矿，其他工具姿势不变。
- 野猪先显示红色感叹号警觉再追击，发现和追击保持距离分离、扩大活动范围；攻击锁定目标身份独立完成，起手后至结束持续判当前距离/遮挡，最多一次命中，离开则落空，结束后不补判。
- 朝向只由有意义的主动移动决定，受击仅小幅击退/原短暂硬直，位移不翻转；巡逻慢步、追击快步；攻击有躯干后蓄前顶及腿部支撑。
