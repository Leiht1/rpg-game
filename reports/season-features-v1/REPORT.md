# 四季特色表现 V1 · 本地实现与雪层修订

2026-10-24。Godot 4.7.2，项目默认 1280×720，NVIDIA OpenGL Compatibility 原生窗口。未提交、推送或部署；未写正式玩家存档。已有改动清单、修改前文件副本与差异保存在本目录的本地忽略项。

## 已实现

- 沿用权威季节日历和世界时钟，四季轻微色调接入原有光照；夏季延长白昼、冬季缩短白昼，光照、时段文字、身体夜间温差和表盘共用平滑后的时间边界，不改变每日总长度或睡眠流速。
- 春季飞鸟四帧、秋季落叶四帧，屏幕空间稀疏出现；飞鸟有方向、高度和速度变化，落叶有转动与弧线。冬季使用独立雪花分布，修正首版相邻哈希导致的雪花聚条。氛围节点位于 HUD 下方。
- 地面积雪、物体积雪和湖冰独立。雪量随游戏时间累积，在冬季保留，非冬季渐退；不使用本地日期或离线追赶。新增可选 `season_surface` 随原 `body_environment` 原子保存；旧档缺失时从零雪量开始，拒绝非法雪量。
- 27 种现有建筑均摆入样例，其中 22 种允许雪层；按原图顶部轮廓形成雪帽，保留正面材质。雨棚雪材质只在棚布节点，原四柱和柱帽保持实色，沿用原实际遮挡淡化。地板雪斑保持原铺面轮廓与厚边。
- 高级熏制房、铜烤箱重雪时通过原交互和业务校验拒绝使用，反馈简短原因；已有有效燃烧热源按范围逐渐融雪，熄灭、无燃料或超范围无效，降至恢复阈值自动可用。普通储物和墙体不统一禁用，不改业务行的材料、库存或耐久。
- 只对现有湖泊区域数据生成独立冰面遮罩，复用湖岸轮廓；内陆河流、海洋和地图外水面没有一并冻结。冻结后原地形通行查询统一放行冰面，人物采用有限加速、减速和转向惯性，普通地面保留原手感。实体碰撞继续走原物理系统。
- 冻结湖泊的原钓鱼入口、进行中会话和鱼影表现禁用，解冻恢复；背包物品与海岸钓鱼不改。解冻时若人物仍处于湖中，单机与权威移动入口寻找真实可通行且无实体阻挡的岸位，避免永远卡在液态水上。

## 用户反馈后的修订

用户指出“地面的积雪太多了面积太大了……建筑……想要的是积雪”。已撤回原先接近全覆盖的宽软白色地表，以及建筑整片顶部泛冷白的做法。

当前地面用较小、稀疏的不规则雪斑，雪量满值也不将整片地表染白；草地、森林、泥地、岩石区原色与纹理仍为主体。相关面积、尺度、边缘和透明度只在 `data/season_rules.json` 的 `features.ground_snow` 调整。建筑改为沿原画上缘形成哑光暖白雪帽，保留大部分棚布、墙面和木纹；移除可能越出原图轮廓的白边扩展。湖泊冰层仍是独立效果，没有把建筑材质复用为冰材质。

## 素材与候选边界

使用 generate2dsprite → generate2dmedia `route_media.py` → `local:codex-cli`，实际模型记录为 `codex-image_gen`。原图、原提示、路由及哈希在 `art/season-features-v1/generated`；处理脚本为 `tools/season_features_art.py`，候选帧及逐文件哈希在 `prototypes/season-features-v1/provenance.json`。

本批仍是 `pending_user`，没有标记为用户已批准，也没有覆盖正式 PNG。飞鸟、落叶及生成雪纹理只在隔离预览启用；常规入口的积雪、湖冰和季节逻辑已接入，未获批新图不自动转为正式美术。

原图返回尺寸和行间距不同于请求，按实际所有权行边界切帧。雪素材行跨越等分列边界，因此不把这些切片直接当完整雪堆贴在建筑上，只使用内部纹理，由原物体轮廓限制雪层。该项源图布局警告保留，不能称原图严格网格 QA 全通过。视觉自然度仍需用户确认。

## 明确限制与未通过项

- 新美术和本轮雪帽的主观效果尚未获用户具体确认，属于候选，不以技术断言代替批准。
- 夏季没有另加日照光束：沿用已有光照架构和轻微色调，本轮避免额外屏幕叠层。
- 只验证默认窗口和本机双端，没有做全分辨率、异机网络、长期生态平衡、大营地 FPS 或多人负载验收。
- 现有动物使用统一地形查询，因此共享冰面通行状态；没有增加动物专属滑行动画。双端解冻瞬间的岸位恢复没有单独做延迟网络专项。
- 首轮暴露的脚本类型推断错误、测试火源清理不完整、建筑泛白和地面积雪过量均经历修订；早期失败日志留作诊断，不作为最终通过依据。
