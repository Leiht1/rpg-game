## 正式接入与实际架构

当前工程不是 Spine：正式角色为 `assets/hero/cartoon/character.tscn` 的原生 Node2D / Sprite2D / AnimationPlayer 部件动画。此次沿用该架构，不引入 Spine、不改既有动画资源、PNG、关节、碰撞、移动基础速度或世界生成器。新增需求授权本轮生命、饥饿、体力、单种可逆疾病、连续体型和状态界面，覆盖历史禁止身体系统条款。

`scripts/body_state.gd` 统一维护身体；`data/body_rules.json` 配置主要速率与阈值；ItemService 持有唯一实例，玩家、库存和状态 UI 共用。`environment_view.gd` 将世界环境正常推进的 seconds / game minutes 传入身体，不通过日期差追赶。暂停和一天调试预览不推进身体，直接设小时不会扣血或改变体型；倍速按同一环境速度推进。没有离线追赶。

## 实际规则与参数

三属性范围 0–100，新档全部100。一天仍为现实60分钟。饥饿每天消耗65，约92分钟从满降至零。饥饿零本身不扣血；普通走路、拾取、界面、装备不耗体力。奔跑每正常模拟秒耗2，停止高强度活动2秒后每秒恢复1.5；饥饿从0到65平滑提高恢复倍率20%到100%，疾病额外降低至多35%。耗尽后保持步行、进食、拾取和 UI；体力达到12自动解除耗尽限制。

有效砍树/开矿/挖掘各耗1.5/2.5/1.5，挂接 `chunk_stream.chop_tree` / `ItemService.harvest_hit` 的成功提交，早于原子快照。启动动作、空挥、距离失效、每帧及按键重复不额外扣除。一次动作仍由原 action_committed 唯一命中保护，长按下一次动作重新验证体力。不改命中次数、速度与掉落。

饥饿低于25积累营养不足，5以下全速、5–25平滑渐弱；25以上每日减少2累计天。营养不足达到0.75等效游戏天后，仍严重饥饿才积累不适；约再0.75天达到疾病阈值0.45。短暂饥饿不进入疾病。疾病且饥饿低于25时，每60游戏分钟扣2生命，间隔进度保存。补充到25即停止恶化和扣血，35以上每日减轻疾病0.8；解除疾病不会瞬间回血。正常营养且停止重劳动时，每120游戏分钟恢复1生命。

生命≤15进入需要照料/休养状态，停移动和采集，保持背包与食物操作，不死亡、不丢物。没有现成队友或联机救援；实际提供自动单人照料：等待30游戏分钟后逐渐每游戏分钟恢复1生命、2体力，生命达到30恢复行动，同时解除本次严重病情并减轻营养累计。通常约现实2分钟可恢复行动，极低生命约2.5分钟。表现为原地休养与明确状态提示，没有新增躺倒动画或队友救援。

## 食物

现有五种野外 eat 物品按最新反馈降低饥饿收益：野生浆果饥饿+3/生命+1；棕蘑菇+3/+0；野胡萝卜+4/+2；野苹果+4/+0；野花+1/+0。烹饪熟食见上方，原生命收益保持。统一 `can_eat/eat` 先判实际收益再消耗，满饥饿且满生命不消耗食物；有生命收益的食物可在饱腹时治疗。不改变材料用途或配方，不新增药物。`treatment` 效果接口可减轻同一种疾病，当前没有正式药物注册；实际恢复方式为饮食、休养和单人照料。

## 连续体型与动画

`reserve` 是长期能量储备 [-1,1]，由饥饿相对55及奔跑/劳动负担缓慢积分，响应约2游戏天；`build` [-1,1] 每3游戏天最多变化1，缓慢趋近储备。单次进食不修改体型。储备、体型均持久化；体型描述和趋势读取它们而非瞬时饥饿。

`body_shape.gd` 在原动画 seek、装备外观之后，以绝对目标设置两个独立显示节点：`Visual/Pelvis/Torso`（已包含衣身）宽度90%–112%，`Visual/Pelvis/Head/Sprite`宽度95%–106%。高度均不改；正常值等于原 Sprite scale(0.25,0.25)。头部 PNG 内五官头发一起变化，避免拆分错位。原 Head/Pelvis/Arm/Leg/Grip 节点及装备变换不缩放、不平移；左右镜像和底层左手规则保持。前/后/侧及左镜像复用相同映射，背包预览沿用独立正面呼吸并同步体型。没有新胖瘦素材、动画关键帧修改、公共父节点缩放或碰撞修改。
