# 建造背包误报修复 · 2026-10-20

原因：所有建造入口保留选中时的库存快照，原严格比较把鱼/熟食每帧自然更新的 spoilage 视为玩家改动背包。

修复：food_freshness.gd 新增 matches_slots，复用逐格 matches，只忽略 spoilage。campfire_ui.gd、campfire_service.gd、camp_buildings.gd 使用该比较。材料数量、位置、物品与实例元数据仍严格保护。材料扣除及保存/回滚均使用提交时的实时库存，不把新鲜度回退至选择时。

验证：Godot 4.7.2，无头及默认1280×720原生窗口各31项，均0失败。实际复现旧比较失败；验证鱼/熟食自然腐坏不阻断预览与提交；真实数量、槽位移动、ID更换、工具实例/耐久变化被拦截；篝火、木地板、木箱、木栅栏在腐坏后成功建造；四类均注入保存失败并确认建筑与当前库存完整回滚；隔离档读取保留材料和新鲜度（浮点容差1e-7）；玩家user目录JSON/tmp哈希保持一致。

测试：tests/test_build_freshness_v1.gd。测试档仅写本报告目录，忽略入库。初次测试脚手架曾使用空快捷槽及旧出生锚点，修正为背包格与实际入场位置；无产品额外修改。无全量回归、长期人工试玩或逐个建筑美术验收，无素材/存档格式变更。未提交或推送。
