# 木箱UI与背包交互修订

2026-10-19；Godot4.7.2 Stable、默认1280×720原生窗口。

## 改动

- 木箱标题Y从3移到12，中心位置保持；框180×202缩为156×184。格内容48减为40，实际尺寸52减为44；图标边距、数量文字12px与耐久条同步适配。3×3及4px间距保持；旧箱取回页高度220，物品保护保持。
- 背包左右框Z12、木箱Z8；实测发现仅Z调整无法改变Godot鼠标命中顺序，因此在world.gd将世界投放接收层、木箱、背包按此顺序排列。背包遮住箱子时鼠标也命中背包，箱子裸露处仍能双向拖拽，世界投放层不抢箱子目标。
- 背包开启时E不再被ItemUI吞掉，原玩家选择目标/开关箱自然生效；图鉴及原模态输入保护保持。32格4×8改为逻辑序号逐行横排，一键整理算法不改。
- 闭合图217×166与开盖图裁切后的源分辨率不同；原来均无mipmap，缩小采样密度不同。现在两图导入均启用mipmap，wood_chest节点共用LINEAR_WITH_MIPMAPS。宽80、底部Y8与获批PNG字节不变。此措施统一渲染采样、减轻不同缩小比例引起的清晰度跳变；不声称两幅独立画稿的原生笔触与线宽数学相同，主观效果可继续实景复查。

## 文件

scripts/camp_storage_ui.gd、camp_storage_slot.gd、item_ui.gd、camp_building.gd、world.gd；两张正式木箱PNG的.import；新tests/test_chest_ui_v2.gd，前两项旧测试更新当前尺寸/横排预期；UI_ART.md、ITEM_SYSTEM.md、CAMP_BUILD_SYSTEM.md、PROJECT_STATUS.md、DEVLOG.md。未新增/重绘PNG，不改变存档版本、成本或物品。

## 实测

- 新专项窗口20项0失败：缩小框/实际格尺寸、标题位置、横排、绘制优先级、真实重叠鼠标命中、背包保持打开时原E关闭与再打开、原生鼠标双向拖拽、正式图采样、独立保存。
- 新进程restart3项0失败：open、箱内物品、九宫格恢复及正式开盖路径。
- tests/test_inventory_chest_v1.gd直接受影响依赖66项0失败，特别覆盖实际火堆位于背包格后时快捷栏拖回包不投料、两秒血条/连砸、旧箱取回和四种床席碰撞。未重复无关系统测试。
- 两张正式PNG的SHA仍与各自批准manifest一致。open.png为当前实景。
- 第一轮重叠鼠标检查失败，按场景输入顺序修复后通过；不把第一次失败写成通过。

所有测试使用临时同Seed fixture与报告目录隔离存档，不读写玩家档。未测多分辨率、大营地性能或长期人工操作；此前历史报告的同尺寸/列向排列条款已由本轮明确替代。
