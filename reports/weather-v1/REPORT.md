# 天气影响与温度 V1 · 本地隔离验收

日期：2026-10-23。Godot 4.7.2 Stable，项目默认1280×720原生窗口，NVIDIA RTX 5060 / OpenGL Compatibility。

## 实际实现

- 在原 ItemService.body 内新增受潮、连续体感温度、四级寒冷和连续极冷计时；由原 advance_gameplay 统一推进，与天气、睡眠、库存共用原子快照。没有客户端独立结算或离线补算。
- 使用 WorldEnvironment 的真实 blend、昼夜和当前步长；雨伞/遮雨区阻止新增受潮，雨停自然干燥，燃烧且有燃料的篝火/火把加速干燥与回暖。灯具不算热源。
- 现有原生衣物基础保暖与时髦服装 stats.warmth 接入；只有实际装备的衣物才叠加属性，不新增衣服或改变其原有获得/装备开放条件。
- 左下角原生存HUD增加两行文字，点击原HUD打开紧凑、实时详情，沿用原关闭和输入解锁。
- 主手雨伞复用实例、库存、快捷栏及持物组件，无耐久、无移速惩罚、无采集能力。按用户纠正恢复正常比例，只抬原右臂，不新增复杂动作；四向伞面在头顶上方。卸下恢复原臂，其他工具不采用该姿势。
- 简易雨棚独立覆盖3×3格，四个小支柱碰撞与遮雨范围分离；等比大尺寸画稿，顶棚半透明、支柱保留实色。真实床可先后放置于棚下；按实际睡眠根点（与sleep_controller.render一致）判断遮雨。下雨露天床禁止开始睡眠，无雨仍可露天睡。棚本身不供热。
- 原建造扣料、取消、锤毁半额返料、配方及保存失败回滚继续使用。多人移动及动物路径也只被实际支柱阻挡，不把整个雨棚当实心家具。遮雨接口可为未来建筑定义指定独立矩形。

## 配置与初始平衡

唯一参数入口：`data/weather_body_rules.json`；物品与配方沿现有数据文件，姿势登记在`data/held_tools.json`。

当前60现实分钟/游戏日：环境基础22℃、夜间最多-8℃、小雨-6℃、雷暴额外-4℃；湿透最多额外-14℃。温度采用22游戏分钟响应时间，状态恢复增加2℃回差。

小雨每游戏分钟受潮+0.55，雷暴×1.5；自然干燥0.16/游戏分钟，有效热源最多额外0.65。短淋2游戏分钟仅约1.1受潮；没有立即掉血。

微冷/寒冷/极冷进入温度16/9/2℃；体力恢复倍率1/0.9/0.7/0.45，极冷移动仅×0.94。连续极冷120游戏分钟后才每游戏小时扣2生命；现有自然回血、饥饿、精力、死亡/遗物/复活规则保持，因此正常自然回血期间净损失更慢。

雨伞材料木材3、植物纤维8、宽叶4；雨棚木材16、植物纤维12、宽叶8。篝火/火把热源范围在同一配置，严格要求lit且fuel>0。预留季节温度偏移和未来季节天气权重，未实现四季日历。
