## 1024×1024 地图性能实测

正式数据文件：`stress-1024-performance.json`。1280×720 窗口，RTX 3060，关闭垂直同步，渲染运行 90 秒。记录实际墙钟帧间隔，排除首次地图加载及开始后 2 秒；不在计时内截图。前 12 秒包含八方向、快速切向/停步，之后以测试专用 8 倍速度跨区块并在地图边缘折返；额外位移绕过道具碰撞，湖岸及可视覆盖仍检查，正常碰撞由独立物理测试验证。加速位移累计 43680.56 px。

| 指标 | 实测 |
| --- | ---: |
| 有效帧样本 | 110917 |
| 平均帧耗时 | 0.793 ms |
| P95 / P99 帧耗时 | 1.320 / 1.849 ms |
| 最大帧耗时 | 18.444 ms |
| 最大区块主线程挂载 | 1.003 ms |
| 累计加载 / 卸载区块 | 230 / 200 |
| 结束时区块 / 对象 / 总节点 | 30 / 1308 / 2001 |
| 玩家脚下缺块 / 可视范围未就绪帧 | 0 / 0 |
| Godot 静态内存结束 / 峰值 | 62.72 / 62.79 MiB |
| Godot 显存指标 | 136.53 MiB |

本机结果有余量，但最大帧高于 60 FPS 的 16.67 ms 预算，不宣称每帧恒定 60 FPS。内存采样在 25 区块时约 58 MiB，移动期间约 60～63 MiB；Godot 静态内存不等于 Windows 进程总工作集，90 秒不足以证明长期无增长或无泄漏。没有测试低端电脑、4K 窗口或多小时持续运行。

`first-render-performance.json` 为早期诊断，包含截图 GPU 读回开销，与正式性能采样方法不同；不混入正式数据。最终截图另行运行生成。

## 动画质量的明确边界

图片生成可用，图生视频路由不可用。当前动作由生成部件的程序关节变换烘焙；腿脚交替、抬脚与手臂摆动是真实姿态变化，不是整张图平移。图层时间、透明画布、帧序和快速切向经过运行检查。

仍有裁片剪纸感、方向视图切换的姿态差异与左侧镜像光照。12 帧离散取样也不能用几何支撑脚零漂移数字证明视觉上绝无滑步。因此当前为可运行分层初版，**尚非最终发行质量**；不声称手绘逐帧或图生视频动画完成。换装准备完成，但本轮仅一套衣服。
