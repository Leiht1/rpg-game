# 全局界面短淡入淡出 V1

2026-10-19，按用户要求接入所有UI框。打开0.12秒、关闭0.09秒，只改变透明度，无位移/缩放、无新PNG。

统一入口scripts/ui_fade.gd通过节点加入/显隐信号处理，无逐帧遍历场景。覆盖普通Control框、自绘地图、动态悬停/获得提示，以及Popup和确认窗口；只监听本节点显隐变化，父级关闭不重复触发子项动画。新出现的外层纸框同样淡入。

普通界面关闭时实际visible立即为false，原输入/取消逻辑即时生效，RenderingServer保留绘制至0.09秒结束。原生二级窗口在短淡出期拒绝输入，结束隐藏并重算输入阻挡；通过弹出信号取消过期关闭动画，透明背景和边框按原始透明度相乘。悬停卡淡出后释放，获得卡不再使用旧0.3秒退出动画。
