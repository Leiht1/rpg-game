# 本地界面与E投喂修订 · 2026-10-22

本轮仅本地源码修改及默认1280×720窗口专项，未构建分发、部署、联机验证或提交推送。沿用上一轮的资源、采集次数和生存指南实现，不重做无关系统。

## 修改

- 用户截图对应 `assets/environment/stylized_v3/tuft_2.png`，为kind=6不可采集的花朵装饰。正式生成器仅过滤该装饰类型，原文件保留；kind=4/5的草丛和可采集wildflower不删除，不改原地表图/地貌/树木/资源ID。
- 地图标题起点从X40右移至X76，避开左上Esc按钮。地图此前在_input阶段吞掉所有鼠标事件；现仅在真实世界菜单Esc按钮区域把鼠标事件交还GUI，按钮回调在地图打开时优先关闭地图，不打开返回菜单。地图缩放、拖拽及“回到人物”沿用原逻辑。
- 世界表盘右侧的旧操作文字Label在创建后隐藏，其他HUD、快捷栏文字和目标交互提示保留。
- 生存指南在拖动说明下一行新增用户指定的“鼠标右键可使用物品，装备道具”；保留上一轮“可投放”。手写字体、纸张、字号保持，默认窗口底部文字未超出信纸。
- 拥有当前动物可接受的背包/快捷栏食物时，附近提示“E 投喂”并持续显示；E打开世界锚定的小纸布选择框，只含52×52食物图标格，无标题、数量输入或额外说明。相同物品ID只列一格，来自原40格库存；悬停复用原物品完整信息卡。
- 点击格子关闭选择框并调用原animal_feed递食动作，接触时才调用原feed事务，每次1件，信任、冷却、距离、遮挡、来源快照及保存失败回滚规则保持。拖拽投喂入口保留。E/Esc或框外点击可关闭；离开距离、动物离开、没有食物、睡眠或存档保护时自动关闭。
- 持剪刀对羊仍优先“E 剪毛”；没有适合食物时，驯养动物原E跟随/留守切换仍可用。有食物时E优先投喂选择框，不在图标框中添加跟随按钮。没有公开信任计数或具体喂养倒计时。

## 验证

Godot4.7.2 / Compatibility / RTX5060 / Windows，项目默认1280×720；`tests/local_ui_feed_v2.tscn`最终159项通过，日志 `reports/.tmp/local-ui-feed-v2/runtime-final.log` 无脚本错误和退出资源诊断。

- 当前实际已加载景物及出生周围7×7区块生成结果无kind6，其他装饰草丛仍生成。
- 原生M键打开地图、真实鼠标点击Esc仅关闭地图、键盘Esc同样关闭；滚轮缩放和鼠标点击“回到人物”正常。截图复核标题与Esc无重叠。
- 旧操作说明隐藏；新增指南文字与“可投放”同时存在，手写文字内容完整且处于原纸张范围内。
- 野羊无食物不提示、有食物显示E投喂；正确类型筛选、重复ID合并、真实E打开、紧凑尺寸、图标与完整Tooltip卡、真实鼠标点击、动作接触前不扣料、接触后恰好1件和信任+1通过。
- 冷却内不扣料且只给简短原因，Esc关闭不误开主菜单，离开范围自动关闭；食物来源变化不误喂，鸡的种子筛选、羊的剪刀优先和无食物时跟随/留守切换通过。
- 测试全程覆写世界身份、persistent_world=false，不读写真实玩家世界/物品档。未进行联机、异机、多分辨率、长期平衡或全量回归。

过程失败留档：初版测试把其他建筑节点的字符串kind当作整数比较；第二/三版测试把菜单add_child写在单行lambda之后，实际没有挂载菜单，导致Esc断言及后续依赖失败。这两项均为测试夹具问题，已修正后完整重跑；失败版本日志保留，未把过程结果叠加到最终159项。

本轮无新增美术。实际窗口临时图为 `reports/.tmp/local-ui-feed-v2/map.png`、`guide.png`、`feed-choices.png`；用户确认本轮效果后按约定清理，文字报告保留。
