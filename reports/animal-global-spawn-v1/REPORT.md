# 动物全地图刷新修订

2026-10-19。按用户最新要求：全地图初始最多6只，之后每7游戏日新增1只。仅修改动物生成调度、兼容迁移、对应测试和文档；未改养殖数值、美术、围栏/门或其他玩法。

## 当前规则

- `data/animals.json` 权威数值：initial_count=6，spawn_interval=10080游戏分钟。
- 完整地图范围选择固定Seed候选，初始鸡/羊各3个机会，后续交替种类；保持原生态与自然/建筑净空检查，出生间距至少80。每机会最多2048个候选；无安全点则本轮不生成，不强行补足，不在加载区块时重试。
- 初始注册全地图身份，不要求各出生区块已加载。探索再多区块也不增加额度，视觉仅在原加载距离内安装。
- 每经过完整7个在线游戏日，新增至多1只；没有即时补足，也不因野生迁离而提前刷新。沿原游戏时间，正常睡眠同速、暂停停止，不计算离线。
- `animals.spawning` 保存首次标志、单调序列及下一截止时间，同原动物/物品原子快照；不改根存档版本、路径或原有对象格式。原generated字段只为兼容保留，不再随探索增长。
- 旧版无spawning动物档：按稳定身份排序，保留最多6只未迁离且未驯养的自然野生动物；多余自然野生动物删除。驯养动物、繁殖幼崽、已迁离历史身份及其他系统状态保留。已有动物历史的旧档从当前时钟等待完整7日，不再追加初始批。完全没有动物历史则正常执行首次生成。
- 繁殖仍按既有条件单独进行；本修订没有新增全地图繁殖总量限制，也没有修改既有局部同种上限。
