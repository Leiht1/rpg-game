# 云端双人公网性能测试

2026-10-28，源码b3b1b121及当前本地云服配置，Godot4.7.2真实原生双窗口、默认1280×720，NVIDIA RTX3060。同一公司电脑/公网出口连接47.118.18.98:24870；不是两台不同网络设备。

使用独立haotian-test Compose项目、TestData和两个随机凭证测试账号，1536格Seed271828世界。正式服务无在线玩家时暂时停服、同公网端口测试，finally停止测试容器并恢复haotian-game-1。正式10账号完整SHA核对一致，世界/人物仍0，严格TLS检查再次通过。朋友既有服务未修改。

预先60次ICMP：60收/0丢，最小37ms、平均38ms、最大57ms。这是此时段ICMP观测，不是TCP底层零丢包证明。

双端约61秒连续往返移动/三次动作：两端退出0，累计1373次API完成均无失败（统计到采样摘要，后续logout不在摘要内）；无远端人物缺失帧，预测阻塞帧0。客户端帧耗中位16.655/16.660ms，P95 17.524/17.504ms，最大38.207/40.171ms。移动待确认队列峰值18/17，确认年龄峰值482/450ms，短时样本没有达到原1500ms阻塞阈值。

移动API：各259/258次，中位232/233ms，P95 333/347ms，最大495/554ms。玩法快照各152/156次，中位267ms，P95 387/367ms，最大1600/556ms。远端新样本到达间隔中位163/150ms，P95 271/250ms，最大412/417ms。此间隔不是纯粹单程网络时延，客户端有补间。三次本地攻击表现响应约28–30ms，不等于服务器命中确认。

两端首次character冷进入请求19.149/19.251秒，包含云端原生规则进程启动/世界加载，不应混为基础网络RTT；登录请求338/410ms。公网同步请求明显高于38ms Ping，存在TLS/请求、服务排队及规则处理等开销，不能仅从本样本给出各自精确占比。服务端抽样看到部分请求约170–190ms，未进行优化或修改超时参数。

结论：当前云服短时双人可用，未观测掉线、应用请求失败或持续预测停顿，画面基本60FPS；存在约0.23秒的移动确认延迟、远端同步间隔及约19秒首次冷入场等待，不能宣称毫无延迟或所有场景无卡顿。未测异地双设备、Wi-Fi波动、长时间丢包、更多玩家/大营地、矿洞战斗全流程。

测试前置失败：第一轮夹具未带公开证书，登录前失败；修复证书准备后第二轮通过，不计作公网丢包。API状态在临时继承的network_client中于内存计数，未修改正式实现或逐请求打印以干扰帧耗。私有凭证/客户端日志在private（Git排除）；临时测试服务器已停止，测试世界不混入正式Data。

详细数值见metrics.json，服务端时序见server-samples.json，ICMP见icmp.txt。测试脚本cloud_dual.gd复用原性能入口并扩展为60秒，probe_client.gd仅计数。
