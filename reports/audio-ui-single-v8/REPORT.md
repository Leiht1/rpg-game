# 界面声音不叠加 V8

2026-10-20。用户反馈点击按钮、打开地图/背包、关闭按钮存在额外声音重叠，要求仅保留本批替换声音、不叠加。

原因核对：项目统一AudioFX全局绑定按钮点击，同时监听窗口visibility_changed。一次关闭按钮操作会触发点击及关窗事件，原来每条新建播放器、允许并发，所以出现重叠。UI配置中的点击/关闭已经是本批V3，打开为V7短版，没有发现V1/V2与新UI文件同时引用的双播放入口。关闭事件的两文件是本批用户选择的变体，每次随机一条，不是同时播放两条。

修复：界面反馈使用唯一独立AudioStreamPlayer，同输入信号回调在deferred阶段归并，失败>库存操作>开关窗口>通用点击，同级最后一次有效事件优先；新操作换声时先停止旧界面声，不叠加。沿用原各事件限频、增益和当前素材。世界退出通过epoch取消旧待播任务，清空队列及停止UI播放器。世界音效、雨与脚步仍按各自规则播放，不将世界整体静音。

按用户仅保留本批声音的要求，另外停用未选新素材的8类旧事件：木/石建造、木箱开/关、冰箱开/关、灯具开/关。原配置和音频保留；当前33类事件启用，所有启用路径仅本批V3或V7短版。详见 `config-check.json`。四地面脚步继续启用，没有改原自然结束/不补播策略。没有修改任何音频数据、音量、角色动画或存档结构。

验证：Godot4.7.2，项目默认1280×720原生OpenGL窗口，`tests/test_audio_ui_single_v8.gd` **62项0失败，退出码0**，结果 `window.json`。覆盖全部33活动事件仅新路径、8旧事件拒播、真实按钮/背包/地图、真实背包关闭按钮、处理函数先/后连接均仅一声、12次同输入回调归并、失败/库存优先、连续切声唯一播放器、两个关窗变体保留、四脚步启用及独立播放、退出停止/取消队列、玩家JSON哈希前后不变。

退出仍有60个ObjectDB实例及2个资源占用清理诊断；未扩大到世界生命周期排查。未重复全量或多分辨率测试，没有声称进行主观听感验收。声音播放器单通道可由结构与运行断言确认，世界环境声仍可与UI正常并存。无自动提交推送。
