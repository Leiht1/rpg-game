# 废弃营地 V1＋鱼类食用与烹饪 V1 验收

2026-10-20，Godot 4.7.2 stable，默认1280×720。仅完成本轮两主题，未提交或推送。

## 当前入口与试玩

逻辑接入普通 `Start-Playtest.cmd` / Godot F5。新世界首次物品初始化生成营地；已有物品档不追加入营地，现有钓鱼湖鱼和两道料理则可直接使用。不要为验收删除旧存档。

推荐双击根目录 `Start-Abandoned-Fish-Preview.cmd`，或打开 `scenes/abandoned_fish_preview.tscn` 按F6。这是同Seed的独立临时世界，禁用正式身份/物品/环境读写；从第一处废弃营地旁开始，提供石锤、鱼竿，以及湖鱼/卷心菜/木/石/燧石各12。退出不保留试玩进度，不向玩家档投放物品。

1. 装备石锤，靠近箱子/工作台/草席/栅栏，按住E拆除；无锤时不能开箱、制作或睡觉。
2. 箱子最后一锤同时落出50%返材及3格预存物资；拾取后在背包核对种类/数量。
3. 用V建造普通篝火，把木料拖上去点燃，E打开食谱。湖鱼不能生吃；已知烤鱼用湖鱼1。自由搭配选湖鱼1＋卷心菜1，做成蔬菜鱼汤后发现食谱。完成后领取，再从背包食用。
4. 重点看聚落/破栅栏的布局与发现感、返材节奏、物资价值以及两道料理收益。正式重载一致性由隔离磁盘和独立进程测试验证；试玩入口本身故意不保存。

## 实现与保存

三模板、最多3处，完整选址/密度/物资规则见 [ABANDONED_CAMP_SYSTEM.md](../../ABANDONED_CAMP_SYSTEM.md)。包括木箱、工作台、草席/木床、少量铺面和断续栅栏，无新增废弃篝火/门/灯。沿原建筑实例轻量标记废弃，设施功能在选择和服务提交层同时禁用。

最后一锤将建筑移除、返材、完整箱内物品实例及锤耐久写原items同次原子快照，保存失败恢复；落地/拾取/满包/获得提示沿现有流程。批次标记和实例在原buildings中，没有第二套营地/库存存档。旧档缺字段兼容，不按模板恢复已拆建筑。

湖鱼保留ID、原钓鱼奖励与数量限制，新增原逐实例腐坏；普通2.5游戏日、冰箱7游戏日，库存/储物/地面/拆分/整理保留进度。旧鱼无字段按新鲜迁移，非法字段拒绝。其他raw原料保持原规则。

只加烤鱼和蔬菜鱼汤：1鱼→烤鱼，12秒、饥饿18、默认已知；1鱼＋1卷心菜→蔬菜鱼汤，18秒、饥饿28、自由搭配完成发现。共用精确配方、单任务、熄火暂停、待领/满包/重复领取保护和一次获得提示；成品沿原食用及熟食腐坏，不改既有料理参数。腐坏原料可依既有食材消费策略烹饪，本轮没有新增“腐坏材料不可投料”规则。
