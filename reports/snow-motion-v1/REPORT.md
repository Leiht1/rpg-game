# 冬季飘雪世界位置与镜头移动修复

2026-10-24 / Godot4.7.2 stable / Compatibility / RTX5060 / 默认1280×720原生窗口。本轮仅修复飘雪运动，不新增系统、美术或改变积雪/温度/四季玩法；不联机、部署、发布、提交推送，不写玩家档。

## 原因与改动

原 draw_atmosphere 直接按视口宽高和 clock 计算屏幕雪花，没有相机位置参与。时钟本身仍推进，但视野移动时雪层没有跟世界产生应有的相对位移，形成贴屏/悬停观感。

现在115个固定槽保存瞬时世界坐标，每帧独立累计下落与原漂移，再由当前视口相机变换投影到原氛围CanvasLayer。移动不重新初始化雪花、不重置下落相位；仅离开可见世界边缘的粒子循环回收。缩放或大幅换视野同样以真实世界视野回收，进入冬季时在当前视野初始化，非冬季停止显示。暂停保留停止下落规则，但相机移动仍应改变世界雪花的屏幕位置。

保留原雪花数量、颜色、大小与漂移/落速范围。运动参数迁入 data/season_rules.json.features.snow_motion，临时粒子坐标不写存档。spring/autumn原动画与地面/建筑积雪、湖冰代码保持。

## 验证

入口 tests/snow_motion_v1.gd：**177项0失败**，明细 results.json。测试在隔离Camera2D场景使用正式角色原素材、实际飘雪脚本和相机投影，不启动玩家持久世界。

- 静止、上下左右及两条斜向，行走/奔跑两种速度，每种连续12步，相机按真实渲染/物理节奏滚动。
- 累计18539个未跨边缘回收的雪花样本，50ms步长垂直世界位移为0.960938～2.332031单位，持续向下；扣除真实相机位移后屏幕下落分量始终为正。
- 暂停时下落时钟与原世界位置停止，相机移动后屏幕投影仍变化，不贴屏。
- 同一默认窗口内核对既有缩放范围、远距离视野切换后的固定槽循环、离开冬季与再次进入。
- 查看移动起止帧的实际雪点和地面参考网格，相机移动与独立下落同时存在。截图为待确认临时测试媒体。

最初夹具把多步相机位移挤在极少真实物理帧中，导致插值相机矩阵尚未追上目标，暂停投影断言失败；后按真实50ms节奏与相机插值重置取样，未为该问题改游戏相机或暂停规则。最终日志 reports/snow-motion-final.log 无错误或退出诊断。

本轮未运行完整世界探索、联机、多分辨率、长期观感或大型营地性能测试，不把隔离相机检查称为全场景回归。
