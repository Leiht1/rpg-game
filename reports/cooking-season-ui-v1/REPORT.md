# F4切季、自由搭配与圆盘显隐修复

2026-10-24。Godot4.7.2 stable / Compatibility / RTX5060，项目默认1280×720原生窗口。仅本地专项，不联机、部署、发布、提交推送，不写正式玩家档。

## 改动与原因

- F4原环境调试页新增“切换四季（下一季）”按钮，按原日历跳到下一季，保留当前小时；春夏秋冬循环。调试跳历不调用玩法快进，不补算身体、料理、作物或燃料的跨日进度，时间预览运行中先结束预览；沿原快照保存日历。
- 自由搭配下拉闪烁来自详情签名包含完整背包，熟食/鱼肉新鲜度的被动小数变化导致不断clear/rebuild原PopupMenu。改为仅在相关食材种类/数量、所选材料、发现或模式变化时重建；新鲜度被动变化不丢失悬停/焦点。
- 篝火此前只允许精确命中食谱，缺失烤箱已有的保底路径。新增篝火专用保底配方数据，合法食材未命中精确配方时使用现有小杂烩/大杂烩；精确已知或隐藏配方优先。保底选项不进入食谱册、不作为新发现，材料直接按实际选择扣除，原单任务、点火、燃料、暂停、计时、待领、满包和保存回滚保持。数量阈值/产物/时长集中 data/campfire_rules.json；没有新增美术或食物定义。
- 篝火保底ID不能被烤箱当成空配料配方使用；读取旧/新待领任务不误记录成发现。
- 四季圆盘改为时间圆盘的同Canvas子节点，保持原屏幕位置，继承时间圆盘的显示/隐藏/淡化逻辑，修复其他UI打开后单独残留在上层的问题。不逐个窗口补丁。

## 实际验证

入口 tests/cooking_season_ui_v1.gd，最终 **116项0失败**，详见 results.json。临时日志 reports/cooking-season-ui-final.log。

- 实际F4按钮存在、四次切季循环正确、小时及身体状态未快进。
- 截图中蘑菇/萝卜/野果/野花等合法未匹配组合走保底；小组合、精确配方优先、JSON整数浮点兼容，空/非法材料或数量拒绝。
- 真实自由搭配页按钮可开始，PopupMenu打开后80轮被动熟食腐败变化期间条目焦点和菜单保持稳定；另断言新鲜度实际变化，避免无效测试。
- 原界面开始烹饪、逐项扣除材料、重复提交不重复扣、保存失败整体回滚、熄火暂停、再点燃完成、待领任务JSON序列化校验、固定成品领取及防重复领取。
- 保底不冒充食谱发现，不能用篝火保底ID向烤箱请求空材料料理。
- 烹饪面板打开时两圆盘均隐藏，关闭同时恢复；四季圆盘真实父节点及原时间圆盘隐藏继承核对。默认窗口已查看实际界面，开始按钮可用，季节圆盘未遮挡。

首轮任务校验使用了测试夹具的点号键赋值（StringName）而非实际存档JSON字符串键，导致内存字典校验失败；改为显式字符串键，并按真实落盘JSON往返校验，未为测试放宽运行存档校验。早期退出曾有2个ObjectDB实例/1资源占用诊断，最终这轮日志未出现；未扩大为资源系统重构。

本轮没有全量回归、多尺寸、联机或长期人工烹饪平衡。临时测试截图保留待确认；物品素材不改。修改主要为 environment_view.gd、campfire_ui.gd、campfire_service.gd、item_service.gd（读取发现保护）、industry_service.gd（边界过滤）和 campfire_rules.json。
