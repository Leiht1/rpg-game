# 播种操作与地板运动细纹修订

2026-10-19，Godot4.7.2 stable / Compatibility / RTX5060。只在项目默认1280×720真实窗口验证。

## 修改

- 新增 `scripts/planting_ui.gd`，复用获准纸布与种子图标：空闲耕地E打开400×300小窗，列出原库存实际种子/数量，点击直接种植；没有种子时明确显示“没有种子”。不需要快捷栏分配或二次确认。支持关闭/E/Esc，菜单拦截角色/快捷键，睡眠开始会退出并交还原睡眠输入。
- `planting.gd` 按点击传入的种子ID从原库存原子扣除1粒，不再读取selected槽。点击前重查地块、距离和种子；失效、缺种、存档失败不错误消耗。沿原库存保存，不新增库存或保存格式。
- `world.gd` 注册选择框，`world_interaction.gd` 将sow交给小窗、提示为“E选择种子”，`item_ui.gd` 接入窗口关闭与输入锁。种子物品、耕地说明及隔离试玩提示同步新操作。原完整种植测试调用更新为显式种子参数，本次未重复无关全量循环。
- 石锤拆除本来就整块移除且耕地材料成本为空；没有添加返种逻辑或正常收获。本次专门验证生长中锤毁后地块/作物节点消失，库存与世界没有返种/产物，再启动也不会补发。
- 木地板顶图缩小到96×64时原线性采样未使用mipmap。现只修改 `assets/buildings/v3/wood-top.png.import` 的mipmap生成及 `camp_building.gd` 木地板节点的采样模式；预览同规则。原PNG、地板格/比例/拼接、相机平滑、物理插值均不改。

## 实际验证

- 种子选择真实窗口自动化20项0失败：E开窗、无种子提示、背包种子无快捷栏要求、三按钮各自一键种植、唯一扣料、无二次确认、菜单拦截快捷键、睡眠输入交还、重复点击保护、种子移走/地块变化、失败保存回滚、锤毁及无返种。见 `seed-menu-checks.json`、[实景](seed-menu.png)。
- 另一个新进程3项0失败：从报告目录独立快照恢复，土地仍不存在，种子数量仍为已扣后的数量，没有作物或种子掉落；见 `restart-checks.json`。
- GPU用同一真实木地板绘制器，在8个亚像素位置对比旧线性采样与新mipmap采样。参考为同一PNG先以Lanczos缩至实际96×64，再在相同位置绘制；RGB绝对误差比值0.211289，低于设定0.8门槛。该值衡量缩小采样误差，不等同于显示设备上的主观“重影评分”。见 `floor-sampling.json`、[旧采样](floor-old-sampling.png)、[新采样](floor-mipmap.png)。离屏图是材质单位测试，没有改变项目窗口分辨率。
- 真实默认窗口角色以原310速度先右、再左、下、上奔跑，每方向18物理帧，均实际移动；正式地板节点均使用新采样。保存并复核四次转向画面。见 `floor-running.json` 与 `run-1.png` 至 `run-4.png`。没有调整相机或人物移动参数。

本轮不重新生成美术；源PNG哈希核对见 `source-integrity.json`。测试夹具仅在临时世界摆放地板/耕地与种子，奔跑用例只清理夹具路线上的障碍；不把该布景当作合法建造测试，不读写玩家档。真实文件仅为本报告目录独立存档。

未做无关全量回归、其他分辨率、长期平衡或大规模性能测试。轻微运动观感仍可由用户实际游玩复查，当前受控缩小采样误差已明显下降。本轮完成停止。
