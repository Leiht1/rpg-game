## 根因与改动

| 问题 | 核实的来源 | 本轮处理 |
|---|---|---|
| 横墙每段像一个独立柱块 | 原本所有接点都叠加端柱，横墙原图两端轮廓也反复出现 | 横向直线且不邻门的中间接点不再重复柱；用原横墙图内部连接区连接。端头/转角/T/十字保留唯一柱，门框保留。竖石墙原图/矩形保持 |
| 门错误盖人/整门变形 | 原脚本把带端柱整张图当门扇投影，并以整段根节点排序 | 固定端柱放在真实端点；仅门扇区域参与投影，铰链与碰撞共用角度；24条门扇绘制片按各自脚点Y排序，动画仍0.25秒；边向保留4单位厚度表现 |
| 正常近距离不能关门 | 原先中心距离小于约75即拒绝关门，混淆交互范围与扫掠区 | 100交互距离保持；依横纵/swing±1逐1度采样门扇四边形扫掠区。角色脚底直接按当前位置判断，其他真实物理障碍独立查询。仅固定铰链套接的12单位区不作活动门扇，未豁免整堵相邻墙；重复动画输入反馈等待，保存失败恢复原状态 |
| 地板绿缝 | 裁片bbox虽然贴边，但外轮廓不规则/局部透明；旧代码没有完整铺面底层 | 每块完整96×64木色/灰色底层托住原PNG；不改图、不扩大占用、不改碰撞/比例，石路灰缝保留 |
| 栅栏/门纵向微斜 | 原纵向PNG本身两个柱脚X不相同，不是全局格漂移 | 固定逻辑端点/门轴已统一，未旋转/挤压原图假装修复；另生成柱脚共X的独立候选，待批准 |
| 火把预览拉伸 | 预览强制80×80，建成后按80宽/92高上限等比 | 营地建筑预览直接复用正式绘制器；火把等比约21.6×92，脚底/方向/尺寸一致，无碰撞/交互注册 |
| 家具预览与建成不一致 | 预览不镜像，正式按facing镜像，原PNG又有倾斜透视 | 正式与预览统一原方向，不再镜像；R仅控制边段横纵。真正正对镜头的箱/台另做独立候选。已保存facing字段仍合法读取，未重置档 |
| 结构E查看、建造不能走 | 无用途inspect与placing全局移动锁 | 墙/栅栏/地面/火把无锤时不成为E目标，有锤才拆除；门/箱/工作台功能保留，工作台提示E制作。只解除选位置时移动锁，打开功能面板等原保护保持 |

门碰撞始终随真实门轴角更新，未删除碰撞。开关先保存再动画，动画期间重复输入不翻转目标；区块加载按持久化open/swing恢复最终姿态。没有增加新的持久化动画状态。
