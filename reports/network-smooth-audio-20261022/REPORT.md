# 联机探索同步与全界面点击音效 · 2026-10-22

本轮是在建筑校验优化后，继续处理用户反馈的联机移动断续与菜单无点击声音。仅修改迷雾恢复与音效生命周期，保留前轮 UI/管理员修复。

## 根因与修改

探索区域发生变化时，WorldExploration.restore 原先每次重建整个768×768迷雾图。1536格地图实测恢复25.94–27.04ms；现保留原Image，只更新发生变化的位，恢复5.11–6.46ms。协议、校验、地图内容与存档格式不变。

AudioFX 的播放入口与延后播放曾要求世界存在，导致主菜单、大厅、人物创建等界面没有声音。UI声音现在独立于世界生命周期，切场景不取消当次点击；仍使用原素材、音量、限频、唯一播放器与优先级。空间声音仍须有效世界，关闭按钮仍只播放关闭声。本条覆盖旧V8的“退出世界取消UI音效”规则。

## 验证

Godot4.7.2，默认1280×720原生窗口，隔离HTTPS服务器，1536格地图、两个真实客户端。相同移动采样约3秒：

|阶段|客户端0最大帧时/超过33.4ms|客户端1最大帧时/超过33.4ms|
|---|---|---|
|修改前|49.998ms / 2|66.664ms / 2|
|修改后首轮|16.666ms / 0|16.666ms / 0|
|修改后复核|16.666ms / 0|16.666ms / 0|

两轮两端均各29项通过，未回拉，停止漂移0。首轮两端移动输入积压达到原85条保护上限，分别9/12采样帧处于等待确认；复核未触发保护，最高83/81条。没有放宽原防护来掩盖网络响应慢的问题，不能据此声称任意网络环境完全无卡顿。短采样不等同长期人工体验或异机网络测试。

迷雾专项验证新增探索逐像素一致、清空恢复、Image复用、非法校验拒绝及非整字节边界通过。全界面音效原生窗口验证登录到主菜单、主菜单单机入口、大厅管理入口、人物朝向/肤色/选项菜单、重复回调归并、关闭优先、世界清理后待播点击与无世界脚步拒播全部通过。无头音效初测有2个ObjectDB/1资源退出诊断，随后原生窗口测试未出现该诊断。

客户端与ZIP重建；服务器程序、真实账号/世界及玩家存档未修改。未提交推送。
