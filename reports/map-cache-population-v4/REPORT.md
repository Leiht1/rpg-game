# 地图缓存、动物鱼群翻倍与统一脚步 · V4

2026-10-20 · Godot4.7.2 / Compatibility / RTX5060 / 项目默认1280×720。

本轮完成用户要求的三项修订，没有提交或推送。共332项定向断言0失败，16份既有玩家JSON/tmp内容SHA和文件集合保持不变；所有保存测试位于本报告专用隔离目录，未改真实试玩/正式玩家存档，也未投放测试物品。本轮未修改美术和角色，不新增截图或音频素材，不把此前地图画风候选视作已批准。

## 地图打开与缓存

- 进入世界后即在关闭地图时后台预热人物附近8倍默认视口及保留的上次缩放视口。更新来源仍是世界真实地形与既有探索，不会因缓存或预加载揭雾。
- 当前可见视口优先完成，人物附近默认/保留缩放的缓存优先保留；有上限的LRU由192增到384块，理论原RGB地形数据上限约4.8MiB（不含GPU对齐/元数据）。没有全世界超大纹理或无上限永久缓存。
- 打开预算1.8ms、后台预算0.6ms，均在每行后检查；一行或上传可能使某帧工作略超预算，不承诺绝对硬实时上限。
- 静态层仅在视口、迷雾修订或缓存完成后重绘；动态人物/原路标单独更新。已缓存地形不会因M开关重新采样，不再每帧重做静态地貌绘制。
- 加载提示只看当前地图视口是否缺地形，后台预热其他视口不会让已完整显示的地图误报「绘制中」。滚轮、拖动、回到人物、边缘限制、人物输入保护与原脚步步幅均保持。

**实际验证：**附近预热完成后首次M打开、连续12次M重开均为零新增地形采样；保留缩放、远处拖动后返回默认附近视口也直接命中。把隔离测试玩家置于另一个合法远处位置后，在地图关闭时仅补充9块新地形，旧地形仍在；返回旧位置再打开无新增采样。未知地区依然保持迷雾；首次可见回调前即同步当前迷雾掩码和视口，配置时默认全遮挡，避免已有地形缓存先于迷雾显示。

**限制：**刚进入世界立刻按M而预热尚未结束，或查看已被LRU淘汰的远处区域，仍会渐进补图。地图缓存保留到本次世界运行结束；下次进世界重新后台预热。本轮优化目标是尽量直接显示，而不是承诺任何位置永不加载。

## 动物数量与旧档

唯一数值来源 `data/animals.json`：初始总数6→12（鸡3→6、羊3→6）；每7游戏日新增1→2（每批鸡羊各1）。刷新周期、真实全世界随机选址、生态/净空约束、野生迁离、驯养、成长、产物和繁殖限制不变，不因区块加载重复生成。

`animals.spawning.population_revision=2` 标记本次数量升级。已有初始化世界一次增加相较原初始批新增的6只；原动物ID及完整状态、驯养动物、幼崽、全局时钟、下次刷新时间全部保留，不以当前野生存活数重复补满。补充在世界恢复完整建筑后由原种群入口执行，避免绕过已有建筑净空。位置不足沿原有限尝试宁缺勿滥。

升级随原ItemService原子快照保存，写失败保留源文件；未成功落盘的同一批不会在已提交状态之外重复叠加。重复恢复和独立进程重进都不再次补充。测试特意包含已驯养亲本与幼崽，并验证每7日一鸡一羊及原期限。

## 鱼群数量与旧档

全图上限按**本轮修改前的各世界当前上限**翻倍：至1024格20→40，新1536格28→56。每湖初始随机0–6群、活动上限6；每群仍6条，原1800/320间距、真实水面/安全岸位、耗尽后2–3日随机换位补充、不离线追赶、成功获得才扣鱼等机制保持。

旧鱼群快照缺 `population_revision` 按旧记录读取，保留所有ID、剩余鱼数与补充倒计时后，只添加新额度；新快照写 `population_revision=2` 并沿原存档标脏。原已耗尽鱼群不会提前复活；再加载不补第二次，非法/未来修订保护源档。未修改世界Seed、尺寸、地貌、建筑、商人或资源采集状态。

## 默认窗口测量

- 隔离Seed81273、60FPS上限，进入后等待后台附近预热实际完成约3788ms；这段工作在正常游戏过程中分帧进行，不阻止游戏操作。
- 热缓存首次M按下/松开的完整两帧输入模拟约30.24ms，新增地形采样0；该数值是测试动作完整耗时，不是单帧渲染时间。
- 12次重开与280帧多档平移/缩放压力记录的动作/帧耗时P95 16.89ms，最大33.41ms；最大值包含两帧输入动作，不能直接解释为单帧掉帧。
- 614个后台缓存工作帧P95 16.72ms，最大50.15ms；不抹去该偶发尖峰。后台单帧建图最大1.41ms，行间预算允许少量超时。
- 原生窗口静态内存约124.42MiB；本组常规视图实际缓存15块，增量区域测试最后18块。没有以384块理论容量当作实际已占满，也未做数小时内存增长结论。

性能测试为单机窗口，不是多人并发或服务器压力测试。未来联机共享探索的服务器验证、网络增量和并发保存并未在本轮添加。
