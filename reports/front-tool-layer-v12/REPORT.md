# 正面工具层级、双手与肩部连接

2026-10-18，Godot4.7.2 Stable / Compatibility / OpenGL3.3 / RTX5060。只修本轮显示问题，应用窗口读取project.godot默认1280×720，无窗口分辨率切换或全量回归。

## 修复

原生动作会将ArmR设为behind-parent，导致右手及其HeldTool被Torso盖住；仅将右臂抬前又暴露了原动作肩部位移与旧空闲臂最底层的不足。用户第二张截图指出这两个问题，初版检查不能视为完整角色正确。

生产代码只修改scripts/held_tool.gd：所有通过held_tools.json登记的主手工具，正面统一在动画取样后将右臂放在衣身前，工具仍为ArmR首子节点、原手掌在工具后绘制。没有全局Z或独立世界前景层。

正面劳动双肩绑定当前Torso内部支撑点，随其体型宽度变化；右臂保留原动画旋转与原Grip相对握点，显示位置调整使肩部不悬空。空闲臂复用原ArmL部件/RemoteTransform姿态源，以唯一前景副本显示，旧ArmLBehind隐藏；空闲臂约束为外垂姿势，避免与持握掌/柄交叉遮住。具体接点和角度见共用组件，不在每工具配置重复。

release_pose恢复原左右肩位置、左臂旋转、原背层显示与右臂behind值；下一次动画取样、转向、拾取、卸下均沿原生命周期。背面工具双腿后和侧面接触世界Y排序保持。原角色/工具PNG、角色场景与动画文件、动作时长/命中/奖励/耐久/存档均未修改。

未来主手工具仅登记获批美术/握点等，不写按工具ID特判。当前代码按facing与已注册持握统一处理；临时新工具ID+新动作复用现有获批纹理也自动获得正确层级。规范集中EQUIPMENT_SYSTEM.md，角色约定与AGENTS记录正面劳动的左臂局部例外。

## 诊断与限制

- 初版右臂层级101检查未覆盖空闲掌与肩部，用户指出后继续修复，没有将初版成绩当作最终完整验收。
