# 《风栖原野》角色动作与未来换装规范

版本：`windrest-character-template-5` · 2026-10-15。

本轮用户要求替代旧运行时分层契约。V0.1 使用完整角色序列帧，不实现正式换装系统。旧独立部件生成、切碎、镜像修补和程序关节拼接结果不能作为新衣物模板。

## 1. 统一角色基体（Base Body）

原始身份参考为 `assets/hero/reference/identity.png`，三方向身份参考为 `reference/turnaround.png`；当前实际眼型、姿态和比例以用户已确认的模板 5 完整帧及 `reference/frame-review.png` 为准。固定栗棕短乱发、圆润小脸与完整棕色眼型、鼠尾草绿短外套、奶白内衣与卷袖、赭黄围巾、棕短裤、奶白袜和棕短靴。本轮只有这一套服装。

- 比例以已接受完整帧为实际尺规，约 3 头身；头、胸腔、骨盆与四肢长度沿用同一套结构，不能换方向就换身体。
- 所有运行帧画布 **128×128 RGBA**，脚底世界原点 **(64,112)**，Y 向下。阴影、碰撞体和世界移动独立于图像。
- 基础姿态为 front/back/side 各自 idle 第 0 帧。方向视图可以有真实投影宽度差异，禁止压缩正面制造侧面或背面。
- `modular_plan/` 保存最终帧对应的姿态模板与机器可读契约；角色全帧是最终形状基准，指南标线仅用于对齐，不是另一套可随意变动的骨骼。
- 后续制作可换装基体时，必须按本模板逐帧重绘完整的头部、躯干、骨盆、上下臂、手、上下腿及脚，补全被衣物遮住的肢体，并先单独验收身体连续性。当前穿衣完整帧不能通过抠除衣服自动得到合格基体。
- 不按每帧透明包围盒改变身体尺度；动作中的屈膝、抬脚与小幅重心变化属于姿态，不能被逐帧缩放抹去。

## 2. 统一方向模板（Direction Template）

| 标准方向 | 游戏语义 | 必须成立的观察特征 |
| --- | --- | --- |
| front | 向屏幕下方移动 | 正面肩髋、脸与双眼、胸前围巾结；脚有纵深迈步 |
| back | 向屏幕上方移动 | 后脑发旋、后衣领与外套背部、鞋跟；无脸、无胸前纽扣/围巾结 |
| side | 向屏幕右方移动 | 真侧面鼻尖、单侧眼、耳、前后胸背轮廓，近远肢体遮挡正确 |

向左复用 side 完整帧的水平镜像，镜像中心为脚底原点 X=64；不另调局部部件。当前柔和光照也会随镜像翻转；将来不对称服装、文字图案、单肩饰品需另做左侧模板并验收，不能直接复用镜像。

斜向沿用四向显示：水平分量绝对值大于等于垂直分量时显示 side；否则显示 front/back。停止输入保留最近朝向。方向切换保持同一 walk 相位，不重置为不同支撑脚。

## 3. 统一动作模板（Animation Template）

动作名固定为 `front_idle`、`front_walk`、`back_idle`、`back_walk`、`side_idle`、`side_walk`。最终帧数量、每帧时长和源帧索引以 `animation/` 内配置为准；不能从文件名猜测行列或顺序。

完整帧和姿态模板逐帧一一对应；模板版本包括帧内容及哈希。新增衣物只能追随该版本，不能在同名帧里私自改变动作。idle 第 0 帧为该方向站姿基准；当前使用用户已确认的 v05 四帧呼吸修订，依次为 neutral、inhale、release、exhale。保持现有六个动画名，`front/back/side_idle` 即对应 idle_breathe，左向整帧镜像 side。

本轮最终 walk 为每方向用户已确认的 **8 张不同整身姿势**：正面、背面沿用 v04，侧面采用按 v08 原姿势统一重绘并经用户确认的 v11 take2，索引 0..7。侧面第 5 帧保留低位收腿、第 6 帧左手在背后少量露出的要求；v09 改动作候选弃用。前、背、右视图各有完整周期，左视图整帧镜像。最终姿态以完整图和验收记录为准，不能把生成提示词或相位标签当作已验证的解剖事实。禁止静态整图平移、复制半周期或倒放前半周期冒充完整步态。

| 相位 | 标准用途 |
| --- | --- |
| 0 · phase 0 | 第一组接触姿势 contact_a |
| 1 · phase 0.125 | 第一组下沉过渡 down_a |
| 2 · phase 0.25 | 第一组经过姿势 passing_a；侧面以 v11 第 3 帧完整姿势为准 |
| 3 · phase 0.375 | 第一组迈出过渡 up_a |
| 4 · phase 0.5 | 相反腿接触/承重相位 contact_b；侧面保留 v08/v11 第 5 帧低位收腿 |
| 5 · phase 0.625 | 第二组下沉过渡 down_b；侧面第 6 帧左手在背后少量露出 |
| 6 · phase 0.75 | 第二组经过姿势 passing_b；侧面以 v11 第 7 帧完整姿势为准 |
| 7 · phase 0.875 | 第二组抬升过渡 up_b，随后进入下一周期 |

左右均指角色自身。背视接触脚存在向屏幕上方的透视投影，鞋底最低像素可能属于后摆脚；不能把每帧透明包围盒底边强行拉到同一条地面线。共享原点是身体在地图中的脚下基准，真实鞋底像素会随动作与透视变化，不作为固定常数。

walk 源帧为 `art/hero_consistency_preview_v04/` 的 front/back_walk_preview 与 `art/hero_v08_pose_redraw_preview_v11/` 的 right_walk_preview，索引均为 `[0,1,2,3,4,5,6,7]`，right 对应 side。本轮只替换 8 张 side_walk；正背行走 16 张及全部 idle 12 张与模板 4 字节一致。24 张已确认 128×128 PNG 原样复制，scale=1、offset=(0,0)，不沿用历史 256→140 的映射，也不重新对齐。

idle 源帧为 `art/hero_sequence_repair_preview_v05/` 的 front/back/right_idle_preview 各 `[0,1,2,3]`，right 对应 side。12 张已确认 128×128 PNG 原样复制，不再缩放或重新对齐；正面/侧面保留双脚修订，背面保留 v04。共享脚底原点 (64,112)，源图的完整帧注册参数继续保留。替换前模板 4 的完整资源和规则备份于 `art/hero_v11_runtime_v05/previous_runtime/` 及 `previous_*`；更早模板 3 备份仍保留。

`animation/registration.json` 固定源图路径、源哈希和统一变换，`modular_plan/template.json` 固定 36 张最终帧哈希、相位和时间轴。各方向的轻微线条/体型差和镜像光照仍保留为已确认素材的边界；不通过运行时额外缩放或平移冒充呼吸。

idle 呼吸每张 27 个 60 Hz tick，即 450 ms，四帧共 108 tick / 1.8 秒；没有眨眼动画。读取 SpriteFrames 的相对帧时长与动画速度计算时间，不能把导出的 60 Hz speed 误当成每秒 60 张姿势。walk 参考时间轴每张 5 tick，完整周期 40 tick，即约 0.6667 秒、12 张/秒，对应参考速度 100 px/s、参考周期距离 `200/3 ≈ 66.6667 px`。当前正常移动速度为 **200 px/s**，实际步频按用户要求保持原来的 **13.8 张/秒**、约 0.5797 秒/周期；运行周期距离调整为 `8000/69 ≈ 115.9420 px`，继续按实际位移推进。参考预览时间轴、参考周期距离与运行周期距离须区分。未来增加中间帧必须提高模板版本并重绘所有依赖模块，不能只改变某件衣服的时间轴。

时间推进使用碰撞后的实际位移：`phase = travelled_distance / stride_world_units`。所有方向共用 phase。停步进入当前方向 idle，idle 使用独立时间钟；无实际移动不能继续播放走路。角色位移速度与周期距离统一配置，不能按不同图层各开计时器。

## 4. 后续换装的正确做法

后续发型、上衣、裤子、鞋子、饰品必须针对 **同方向、同动作、同帧** 的姿态模板逐帧绘制；每个模块拥有与整身帧相同的透明画布、原点、源尺度和时间轴。服装可以自然改变轮廓，但不能移动关节、脚底或角色碰撞体。

**不能再从一张完整立绘拆分后直接拿来拼多方向角色。不允许“先画完整人，再临时切碎”当作换装系统。** 旧 `art/parts`、`art/rig` 仅留历史追溯，不作为本模板的模块输入。

制作流程：锁定完整帧模板版本 → 完整基础身体逐帧绘制/验收 → 针对同一模板绘制模块 → 检查方向与每帧遮挡 → 全帧叠合对照样板 → 待机、行走与快速转向验收。不能用局部偏移、旋转或缩放去掩盖不符合模板的衣物。

## 5. 推荐结构：逐帧模块换装

| 模块 | 内容与遮挡要求 |
| --- | --- |
| base_body | 完整身体；近远手脚可拆子层，但共用同一帧索引 |
| hair | 前发/后发按方向和动作遮挡头部、颈部，不能只镜像刘海制造背面 |
| top | 躯干、近/远袖，跟随真实肩肘姿态；覆盖层下身体仍完整 |
| bottom | 腰/裤筒，逐帧追随骨盆与髋膝；不能用一块裤图旋转替代 |
| shoes | 两只鞋跟随各自脚、深度、接触相位与鞋底投影 |
| accessory | 围巾/帽/前后饰物等；前后子层按实际遮挡拆分，不穿透身体 |

模块的文件键建议为 `<module>/<direction>/<action>/<frame>.png`，并登记 `template_version`、帧哈希、共享画布、共享 anchor 与渲染次序。共享一套权威帧索引；每帧遮挡次序允许由数据定义。

front 基准：后发/远肢 → 身体与裤装 → 上衣 → 近肢及袖/鞋 → 头与前发/胸前围巾。back 基准：远肢 → 身体/裤装 → 外套背面 → 近肢/袖/鞋 → 后脑发与后饰物。side 基准：远手脚及对应衣物 → 身体/裤装/上衣 → 近手脚及对应衣物 → 前发及方向正确的饰物。接触/经过帧必须对照完整帧确认遮挡，不能把这份基准当成永远固定的全局层序。

**骨骼 / 部件式换装需单独论证。** 必须先解决统一方向基体、完整遮挡、关节形变与逐帧样板一致性；当前阶段不切换到该方案。

## 6. 本轮完整角色序列帧的用途

**本轮产出的完整角色序列帧，既是当前 V0.1 的直接可用资源，也是未来模块化换装重绘时的标准样板。** 保存完整帧不是宣称已经制作出隐藏身体和全套服装模块；本轮保留的是统一的身份、方向、逐帧姿态、原点、相位和文件契约，不交付正式换装系统。

任何修改模板比例、相位或方向投影的工作都须提高模板版本，重新验收依赖模块；地图生成器版本不因角色资源修改而变化。本轮完成即停止。
